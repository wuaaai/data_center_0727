# 批量上传 & 地区权限分配 — 合并开发方案

> 版本: v3.0 | 日期: 2026-07-27 | 优先级: P0 核心亮点

---

## 一、为什么合并？

04（批量上传方案）和 05（地区权限分配方案）**在用户场景上是同一条流程**：

```
管理员有 500 份各地市文件要入库
  → 需要批量上传（04 解决）
    → 需要分配地区权限（05 解决）
      → 两个问题在一次操作中同时面对
```

**分开设计 → 分开开发 → 接口对不上 → 用户割裂体验**

合并后是一次完整的"批量导入"操作，用户只感知一个入口、一个流程。

## 三、统一后的接口设计（合二为一）

全部挂在 `/file_parse` 下，一次请求搞定上传+分配。

### POST /file_parse — 核心入口（合并版）

```bash
# 最简用法：全部默认
curl -X POST ".../file_parse" \
  -F "files=@a.pdf" -F "files=@b.pdf" \
  -F "format=markdown"

# 完整用法：带分配信息
curl -X POST ".../file_parse" \
  -F "files=@石家庄预算.pdf" \
  -F "files=@邯郸计划.pdf" \
  -F "files=@保定执行.pdf" \
  -F "format=markdown" \
  -F "mode=async" \
  -F "kb_id=kb_budget" \
  -F "default_region_code=130000000" \      # 默认地区
  -F "tags=预算,2026" \
  -F "auto_allocate=true"                   # 启用智能分配
```

**扩展参数：**

| 参数 | 说明 |
|------|------|
| `default_region_code` | 默认地区（所有文件的兜底值） |
| `auto_allocate` | 是否启用文件名规则自动匹配地区 |
| `per_file_regions` | JSON: `[{"filename":"a.pdf","region":"1301000"},...]` — 精确到文件的分配 |

### 辅助接口

| 方法 | URL | 说明 |
|------|-----|------|
| POST | `/file_parse/preview-allocation` | 预览文件列表的自动分配结果（上传前查看） |
| POST | `/file_parse/scan-directory` | 扫描服务器目录 → 返回目录树 + 自动分配建议 |
| POST | `/file_parse/import-directory` | 确认并导入扫描的目录 |
| GET | `/file_parse/batch/{batch_id}` | 批量进度（含各地区的进度分布） |
| GET | `/region-match-rules` | 地区匹配规则 CRUD |
| POST | `/region-match-rules` | 新增匹配规则 |

## 五、实施任务（合并后）

### 任务 D1: 统一 `/file_parse` 路由 + 地区分配参数
**文件:** 新建 `routes/file_parse.py`，在 `main.py` 注册
- POST `/file_parse` — 整合上传+区域分配
- POST `/file_parse/preview-allocation` — 分配预览
- GET/POST `/region-match-rules` — 规则管理

### 任务 D2: 文件名规则自动匹配引擎
**文件:** 新建 `ragdata_manager/region_matcher.py`
- 内置 11 地市 + 省本级的默认关键词规则
- 支持中文全称/简称/拼音/区划编码
- 可扩展自定义规则

### 任务 D3: 目录扫描 + 自动映射
**文件:** `routes/file_parse.py`
- 递归扫描服务器目录
- 子目录名 → 地区代码自动映射
- 子目录名 → 知识库/标签映射

### 任务 D4: 批量进度面板（前端）
**文件:** 新建 `BatchImportPanel.vue`
- 包含文件选择区 + 地区分组区 + 进度条
- SSE 实时推送

### 任务 D5: 拖拽分配组件（前端）
**文件:** 新建 `RegionFileGroup.vue`、`UnassignedFilePool.vue`
- 文件卡片 → 拖入地区分组
- 多选+批量拖拽

### 任务 D6: 后端性能优化（04 的批量优化部分）
**文件:** `rag_ingest.py`、`mineru_app/model_manager.py`
- 批量 Embedding、COPY 写入、动态并发
