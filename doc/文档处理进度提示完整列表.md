# 文档处理进度提示完整列表（全链路）

## 一、非 processing 状态（data_processing_center 后端, routes.py）

| 进度文字 | 对应状态 | 说明 |
|----------|---------|------|
| 排队等待处理... | queued | 刚上传，进入后台队列 |
| 等待模型服务就绪... | queued | MinerU 模型还没预热完，轮询等待中 |
| 正在提交到模型服务... | queued | 正在把文件上传给 MinerU 解析服务 |
| 已提交到模型服务，等待处理... | processing | MinerU 已收到任务，排队等 worker |
| 处理完成 | completed | 解析成功，DOCX 可下载 |
| 处理超时: 文档处理超时 (>600秒) | failed | 10分钟还没解析完 |
| 处理失败: {具体错误} | failed | 其他异常 |
| 正在入库到 RAG 知识库... | ingesting | 向量化写入 pgvector |
| 入库完成 | ingested | 切片已写入向量库 |
| 入库失败 | completed | 入库出错（状态回退） |
| 入库超时 | completed | 入库超时（状态回退） |
| 入库异常 | completed | 入库异常（状态回退） |
| 已从知识库移除 | completed | 出库完成 |
| 已就绪（跳过处理，可直接入库） | completed | direct-upload 直传 |

## 二、processing 状态详细进度（MinerU 模型服务, model_manager.py）

### 环节 1/4 — 加载引擎

| 进度文字 | 百分比 | 触发条件 | 耗时 |
|---------|--------|---------|------|
| `[环节 1/4] 加载引擎：正在加载模型，首次约需10秒...` | 0% | 任务开始 | <1秒 |

### 环节 2/4 — 解析文档（核心阶段，占总耗时 99%）

由 tqdm 实时进度条驱动，每个子步骤都带百分比：

| 进度文字（中文） | tqdm 英文 | 说明 |
|---------|--------|------|
| `[环节 2/4] 解析文档：版面检测 XX% (M/N)` | Layout Predict | 识别每页是单栏/双栏/混排 |
| `[环节 2/4] 解析文档：公式识别 XX% (M/N)` | MFR Predict | 识别数学公式 |
| `[环节 2/4] 解析文档：表格OCR检测 XX% (M/N)` | Table-ocr det | 检测表格中文字区域 |
| `[环节 2/4] 解析文档：无线表格识别 XX% (M/N)` | Table-wireless Predict | 无边框表格结构化 |
| `[环节 2/4] 解析文档：有线表格识别 XX% (M/N)` | Table-wired Predict | 有边框表格结构化 |
| `[环节 2/4] 解析文档：OCR文字检测 XX% (M/N)` | OCR-det ch | 检测所有文字区域 |
| `[环节 2/4] 解析文档：OCR文字识别 XX% (M/N)` | OCR-rec Predict | 识别文字内容（最耗时） |
| `[环节 2/4] 解析文档：印章检测 XX% (M/N)` | Seal Predict | 检测印章区域 |
| `[环节 2/4] 解析文档：页面合成 XX% (M/N)` | Processing pages | 中间结果合成 JSON |

## 三、前端显示规则

| 条件 | 显示效果 |
|------|---------|
| `progress_pct > 0` | 蓝色进度条 `<el-progress>` + 下方中文进度文字 |
| `progress_pct == 0` | 纯文字，无进度条 |
| 状态 = completed | 显示"处理完成"，无进度条 |
| 状态 = failed | 显示错误信息 |
| 状态 = ingesting | 显示"正在入库到 RAG 知识库..." |
| 状态 = ingested | 显示"入库完成" |
