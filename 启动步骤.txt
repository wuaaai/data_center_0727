  启动步骤

  所有代码都在 E:\Develop_docu\sql_0722_center\data_processing_center 下。
  mineru_0720 是旧的 MinerU 原始项目副本（可删除），已经不需要了。

  1. 启动后端（端口 8001）—— 必须启动

  cd E:\Develop_docu\sql_0722_center\data_processing_center
  .venv\Scripts\python.exe main.py

  知识库管理、文档 CRUD、启用/禁用、元数据查看全部可用。

  2. 启动前端（端口 8000）—— 必须启动

  cd E:\Develop_docu\sql_0722_center\data_processing_center\app
  npm run dev

  3. （可选）启动文档解析引擎

  MinerU 模型服务（端口 8003），仅上传文档需要：
  cd E:\Develop_docu\sql_0722_center\mineru_0720
  .venv\Scripts\python.exe web_app\server.py
  等待 3-5 分钟模型预热。
  验证：浏览器打开 http://127.0.0.1:8003/api/status，看到 "model_loaded":true

  或者使用内网 Maas 引擎（生产环境）：
  set PARSE_ENGINE=maas
  （环境变量切换，无需启动 MinerU 服务）

  4. 打开浏览器 http://localhost:8000



  1. 双击 E:\Develop_docu\sql_0722_center\启动项目.bat
     或手动:
     cd mineru_0720 && .venv\Scripts\python.exe web_app\server.py   ← 8003，预热~10秒
     cd data_processing_center && .venv\Scripts\python.exe main.py   ← 8001

  3. 等顶部状态栏绿点亮起即可开始上传文档
